# API contract hardening: verification evidence

Date: 2026-10-18. This records local checks of uncommitted work, not a release or GitHub delivery status.
The [accepted implementation plan](../plans/10.0.0-api-contract-hardening.md) maps each change to its ADR and contains the message-only history mapping.
The ownership decision itself is [ADR 0036](../adr/0036-structural-message-snapshots-and-borrowed-content.md).

## Red before green

  production fixes. Date and borrowed-resource controls already passed. Failures reproduced constructor/builder/getter/serialized aliases,
  supplied byte-array aliasing and address-only name replacement. Local log: `tmp/api-hardening-email-red.log`.

  implementation. Assertions subsequently exercise their actual behavior rather than merely checking method existence.
- SmimeReceiveBoundaryTest and OutlookSmimeDecryptionStatusTest: 13 tests, 8 assertion failures and no errors before the S/MIME fixes. Six routes
  silently ignored explicit requests without the module; two Outlook cases misreported encryption. Existing bad-password and independent-attachment
  controls passed. The red collection used failure-ignore deliberately; its Maven success banner is not treated as test success.
- OpenPgpDetailsBoundaryTest reproduced the missing internal implementation before the move.
- PublicJavadocContractCheck first failed on the absent published Recipient#getName. A subsequent fresh Javadoc build also caught the missing
  recipient-group setter link, which was corrected. This verifies generated HTML rather than relying on compiled Lombok methods.
- CliBuilderCompanionsTest: four JDK 17 tests, exactly one expected red for empty generated descriptions. After six concise help openers were
  added alongside setter links, all four passed. Mapping, exclusions and real logging-only execution were already green in the red run.

## Boundaries and delivery

No live mail, manual benchmarks or SpotBugs. Existing harness unit tests remain part of ordinary verification; no pressure/benchmark workload
was launched. At verification time, there was no push, issue change or new implementation commit. The selected nine Java and two website commit messages were reworded with
