## Contracts to implement

- Copy owned metadata structures, nested headers, supplied arrays and dates. Preserve order, duplicates, accepted nulls, UIDs and internal sources.
  Email collections are unmodifiable; builder getters return detached modifiable copies. Borrow arbitrary DataSources/MimeMessages without reads.
- Address-only parsing changes only the address. Preserve existing malformed-input tolerance.
- Exact builders gain recipient/sender/DSN/component/ENVID clears and metadata getters. Composed builders gain applicable component clears.
  Clear restores absence/fallback, not suppression, empty reverse path or removal of locks. Preserve unrelated DSN components and exact bytes.
- Add SMTP field clears, callback-registration clears, opportunistic-TLS inspection/reset and legacy-content reset. Preserve SMTP overload/null
  behavior. Clear callbacks without closing application resources. Resets use centralized key-builder defaults and retain lock validation.
- Add retry attempt/delay/combined schedule clears; combined clearing retains resource budgets. Add OpenPGP key-ID clear and algorithm resets.
- Explicit S/MIME decryption loads the requested module at use. Accurate owning-envelope facts do not aggregate unrelated attachments; preserve
  crypto/I/O failures and independent signature facts. No new catch-and-ignore behavior.
- Keep OpenPGP reading public and concrete assembly internal to core, including serialization fallback. Use Lombok for internal assembly.
- Publish explicit getters without changing signatures/value semantics; verify fresh HTML, source-of-truth links and hidden internal assembly.
- Update docs and ADR links. Migration only for released mutation/recipient/S/MIME behavior, never intermediate unreleased changes.
