## Behavior and API

- Copy the nullable enabled flag and optional address for both notification families, preserving unset, automatic, explicit and disabled states.
- Close only streams the attachment convenience method opens; direct stream access remains caller-owned. Preserve read/close exception ordering.
- Exclude private-key bytes from DKIM builder rendering and check comparable security configuration renderings.
- Share internal pool validation: core >= 0, max >= 1, claim/idle >= 0, optional creation age > 0, resolved core <= max. Preserve zero meanings
  and setter ordering; validate inherited combinations before pool resources are created.
- Add stored-choice inspection to failover/retry and reviewed DKIM/S/MIME builders. Do not resolve derived/provider defaults during inspection.
- Add named clears for optional DKIM length/exclusions/canonicalization/signing algorithm and S/MIME signing/encapsulation/cipher algorithms.
  Restore absence, not a newly invented provider default; retain existing setters and key material.
- Add resetDebugLogging(), clearDebugPrinter(), clearDebugOutput() and nullable getDebugOutput(). The output setters select one target;
  clearing either restores the captured configured target or absence. Do not toggle logging or close borrowed streams.
- Keep public builders explicit with setter-owned documentation and linked companions. No new properties, foreign dependencies or configuration abstraction.
